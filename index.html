關於我

從植物病理，到程式碼

大學與碩士都在研究植物的病蟲害防治。畢業後投入相關領域一段時間，漸漸發現自己想要的其實是一個能持續學習、持續解決具體問題的工作型態——於是我開始自學程式，並在 2022 年正式踏入軟體工程的世界。

這幾年沒有走一條特別平順的路：從一人扛下整個客服平台的手忙腳亂，到參與一個橫跨近三年、牽動台電再生能源購電費用的系統重構，再到現在於半導體產業駐點，學習用 Python 與 Helm 處理過去完全陌生的自動化與部署工作。

每一段經歷都逼著我在陌生的地方，重新學會怎麼把事情做好。這大概是這幾年來，我覺得最值得說的故事。

工作經歷

三段經歷，三種收穫

  1. 2025.05 — 現在

    緯思科技 資深軟體工程師

    目前以駐點工程師的身分，與客戶端工程師合作，負責約 10 個 Java Spring Boot 專案的版本升級（2.x → 2.7.18），並針對其中 3 個專案完成 unit test 補寫、弱點掃描修正與 sanity check 驗證腳本撰寫。

    同時也參與 2 個系統的 Helm 設定標準化與金絲雀部署遷移，透過 8 個階段性 PR 逐步導入，並將其中 6 個步驟獨立開發為 Python 自動化腳本。

    這是我第一次接觸 Python 與 Kubernetes 相關的部署設定，也是這幾年來最直接感受到「現學現用」的一段經歷——沒有人手把手教，只能靠既有經驗拆解問題、動手驗證。
  2. 2022.06 — 2025.02

    三商電腦 全端工程師

    加入約 20 人的駐點團隊，參與台電再生能源購電費用核算系統的重構專案，將原本各自獨立的申辦、契約、開票三套系統整併為一套大系統。我負責契約模組的全端開發（Java Spring MVC / MyBatis / Oracle SQL），處理業者合約與機組資料相關功能。

    加入約一年後，因團隊協作上的考量，開始以工程師角度協助 SA 評估需求可行性、參與技術方案討論，逐漸從單純的功能開發者，成長為能與團隊共同規劃的角色。

    這將近三年的經歷，是我目前為止投入時間最長、也最完整地體會「大型系統怎麼被一步步蓋起來」的一段旅程。
  3. 2022.02 — 2022.06

    碩網資訊 全端工程師

    轉職後的第一份工作，負責智能客服平台的全端開發與維運（Backbone.js / Java Spring MVC / MySQL）。任職兩個月後，兩位帶我入門的前輩相繼離職，團隊只剩下 PM 和我獨自負責整個客服平台，同時處理最多 5 個客戶的需求單。

    有一次客戶反映系統跳轉失敗，我在客戶端現場查了好幾天，最後透過 log 與資料庫紀錄，才發現問題出在合作方系統傳來的網址存在 http 與 https 協定不一致——不是我們系統的問題，但那幾天讓我體會到，遇到問題時最重要的是先把證據找齊，再下結論。
